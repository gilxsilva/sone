# Sources and editorial approach

The collection combines original reflective prompts with symbolic motifs. It is not a scientific decoding system, therapy, a diagnosis, or a forecast. Sources are supplied so readers can explore other interpretations, not to validate the reading.

All descriptions and questions are written for Soñé. They are not copied dictionary entries. Translations preserve that distinction. Motifs vary between communities; no entry claims to represent all Mexican folklore or any other culture.

Mirrors and clocks are original editorial additions based on everyday metaphors. The initial twenty entries are editorial associations and family-story motifs; they are not attributed quotations or verified historical claims.

Some references use confident or predictive wording. Soñé deliberately does not reproduce those claims as facts. Associations about loyalty, transition, growth, or time are presented as optional starting points. The visitor's own context takes precedence.

For a general definition of dreaming, see the [APA Dictionary of Psychology](https://dictionary.apa.org/dream). This reference does not validate the symbolic associations in the collection.
